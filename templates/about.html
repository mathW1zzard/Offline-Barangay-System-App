{{ app_title }}

Version {{ app_version }} Released {{ released }} · Installed for {{ barangay_name }}

An offline system for barangay offices: a queue with priority lanes, the visitor logbook, and certificates printed with the barangay's own design. One Windows desktop app, with no internet and no server to maintain.

{{ icon('check', 22) }} What's New in Version {{ app_version }}

  • Each certificate can use the barangay's own design, loaded from a Word (.docx) file or a picture of the whole page.
  • The control number, nationality and CTC details (number, place and date) can go anywhere in the wording.
  • Bold, centre, right and indent in the wording, plus the text size, line spacing and the space above the signatures for each certificate.
  • A new header: Republic of the Philippines, municipality and province, barangay name, up to three logos, and an office line in the barangay's colour.
  • Choose who signs each certificate: the Punong Barangay, the Secretary, or both.
  • The client's address is required at registration and appears on the attendance printout (never on the queue slip).
  • Logos and designs are saved inside the database, so one backup holds everything.

{{ icon('file-text', 22) }} Quick Help

Writing certificate wording (Templates)

To do this Press or type
Bold Select the words, then Ctrl + B (the words get ** on each side)
Centre a line Ctrl + E, or start the line with >>
Line on the right The Right button, or start the line with >>>
Indent / remove the indent Tab / Shift + Tab
New line / new paragraph Enter / Enter twice; each extra Enter adds an empty line
The client's details Use the field buttons, e.g. {Client name} or {Control number}, so they are spelled right
Leave the wording box Esc, then Tab

If something goes wrong

The queue slip does not print

Check that the printer is on, has paper, and its cable is plugged in. Then open {% if can(request, 'maintenance') %}Maintenance{% else %}Maintenance (or ask the administrator){% endif %}, choose the printer under Receipt printer, and press Print test slip.

I forgot my password

On the login page, click Forgot password? and type the recovery key (it starts with BQS-) that was saved during first-time setup. If the recovery key is lost too, contact the developer.

A certificate prints on two pages

Check that the paper in the printer is the size the design needs (Letter, A4 or long bond). If it still does not fit, lower the text size or the line spacing of that certificate in Templates; the preview warns you when the wording is too long.

We need old records back, or the computer broke

The app makes a backup every day and keeps one for each of the last 14 days it was used. You can also save a copy to a USB drive on the Maintenance page. Do not copy or replace the app's files yourself: contact the developer and include the system details above.

{{ icon('shield', 22) }} Your Data and Privacy

  • Everything is stored only on this computer, in the data folder shown above. The app does not use the internet and sends nothing anywhere.
  • The records hold clients' personal information, so the Data Privacy Act of 2012 (RA 10173) applies. See the Terms of Use below.
  • Only people with an account can open the records. Keep passwords private and log out before you leave the computer.
  • Backups hold the same personal information. Keep any USB drive with a backup in a locked place.
